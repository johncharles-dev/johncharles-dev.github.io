Experience

Where I've Worked

AI Intern

HTX (Home Team Science and Technology Agency), Singapore

Nov 2025 – Aug 2026

Part-time SUTD industry attachment with the Process Modelling & Simulation team, building an image-to-3D asset pipeline for digital-twin environments.

Built a web tool integrating multiple state-of-the-art generation engines behind a single interface, with interactive segmentation and on-demand GPU memory management — 753 assets generated through it during the internship, cutting creation time from days of manual modelling to under a minute.

Designed an automatic metric-scaling method combining monocular depth estimation, silhouette matching and a zero-shot class-size prior, reducing longest-dimension error from 77.5% to 24.6% MAPE.

Led a systematic evaluation across 305 generated models using ground-truth-free metrics, blinded scoring and paired bootstrap 95% confidence intervals, identifying which segmentation and generation combinations produced the most structurally faithful assets.

Containerised the system with Docker and GPU passthrough and demonstrated it live on an RTX 5090, with pinned dependencies and verified clean-machine installation.
