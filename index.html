Visual grounding API — LLaVA-1.5-7B with LoRA

2026

Team project, SUTD Deep Learning for Enterprise — I built the serving, deployment and evaluation layer

The model localises objects in an image from a natural-language description, predicting boxes through a regression head rather than parsing coordinates out of generated text. My part was everything around it: a FastAPI inference server, sequential model loading to run a 7B model under constrained VRAM, input validation, CORS, and a React interface that draws predicted boxes over the source image.

I ported the container to CUDA 12.8 for Blackwell, which upstream did not support, added docker-compose so the API and front end come up together, set up CI, and owned the evaluation reporting — latency benchmarking, accuracy-at-IoU-threshold, overfitting analysis, bias audit and failure analysis.
